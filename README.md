# Подход — трекер силовых тренировок (Android)

Офлайн-приложение: без аккаунта, без рекламы, всё хранится на устройстве.
Kotlin, Jetpack Compose, Material 3, Room, Coroutines/Flow, DataStore, MVVM. minSdk 29.

## Возможности
- **Тренировки**: программы (создать, изменить, копировать, удалить с подтверждением, перетаскивание упражнений), старт тренировки из программы или пустой.
- **Активная тренировка**: прошлый результат отдельно от текущего, автозаполнение из прошлой тренировки (подходы не отмечаются выполненными), кнопки −/+, цифровая клавиатура, таймер отдыха (60/90/120/180 с, настраивается, уведомление, работает при сворачивании и блокировке), восстановление незавершённой тренировки.
- **Упражнения**: поиск, фильтр по мышцам, избранное, свои упражнения, защита от дублей по названию.
- **Прогресс**: графики, оценка 1RM по формуле Эпли (подписана как оценка), необязательные подсказки прогрессии (вес сами не меняются).
- **История**: просмотр, редактирование, повтор, копирование в программу, удаление.
- **Настройки**: светлая/тёмная/системная тема, кг/фунты, таймер, экспорт CSV и JSON, импорт JSON, резервная копия и восстановление (с проверкой файла и предупреждением о перезаписи).

Объём = Σ(вес × повторы) только там, где он применим; упражнения с собственным весом и «только повторы» не выдаются за полный объём.

## Сборка APK

### Вариант 1 — Android Studio
1. Откройте папку проекта (Android Studio Ladybug или новее, JDK 17).
2. `Build → Build APK(s)` или в терминале: `./gradlew assembleDebug`.
3. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Релизная сборка: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
(подписана отладочным ключом, чтобы её можно было установить из файла; для публикации подставьте свой keystore).

### Вариант 2 — GitHub Actions (без установки Android SDK)
Загрузите проект в репозиторий GitHub. Workflow `.github/workflows/build.yml` сам прогонит тесты, соберёт debug и release APK и выложит их в Artifacts запуска.

## Тесты
- `./gradlew testDebugUnitTest` — все тесты: доменная логика и Robolectric-тесты репозитория/БД (при первом запуске Robolectric скачивает android-all, нужен интернет).
- `bash tools/check-domain.sh` — быстрая проверка доменного слоя без Android SDK (только JDK и Gradle).

Покрытые сценарии: создание и копирование программы, старт тренировки без отметки подходов, отметка/снятие, некорректные значения, сохранение после перезапуска, прошлые результаты и автозаполнение, завершение с неполными подходами, объём с пропусками, правка истории без влияния на другие тренировки, удаление программы/упражнения с сохранением истории, дубли названий, резервная копия и повреждённые файлы.

## Структура
- `domain/` — чистая логика (расчёты, прогрессия, форматы, экспорт/импорт); без Android-зависимостей.
- `data/` — Room (сущности, DAO), репозиторий, DataStore, резервные копии. Слой репозитория изолирован, так что позже можно добавить облачную синхронизацию.
- `timer/` — таймер отдыха (абсолютное время окончания, AlarmManager, уведомление).
- `ui/` — экраны Compose и ViewModel.

## Резервные копии
Экспорт JSON одновременно является форматом резервной копии. Вес хранится в кг независимо от выбранных единиц.
